# Contributing

Thanks for helping with Codixel.

## Ways to help

- Report a bug or a wrong instruction in `SKILL.md` with an issue.
- Suggest a new effect or a better step with an issue first, so it can be talked through before any work.
- Send a pull request for fixes to `SKILL.md`, `README.md` or `core/pixel.js`.

## Pull requests

- Keep each pull request to one change.
- For `core/pixel.js`, include a GIF or a few frames that show the result.
- New effects should come from a real, finished use (a game, a scene), not from a quick test.
- Code has no comments; explain the change in the pull request instead.
- By sending a pull request you agree that your work is released under the MIT License.

## Code of conduct

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
