# Security policy

Codixel is a set of instructions and a small JavaScript file that runs locally. It has no server and stores no data.

## Reporting a problem

If you find something unsafe, for example an instruction in `SKILL.md` that makes the AI run harmful commands, report it privately through [GitHub security advisories](https://github.com/mankidev/codixel/security/advisories/new). Please do not open a public issue for it.

Only the latest version on the `main` branch is supported.
