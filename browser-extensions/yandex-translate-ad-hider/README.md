# Yandex Translate Ad Hider

Локальное расширение для Chrome, Яндекс Браузера и других Chromium-браузеров. Оно скрывает рекламные блоки на `translate.yandex.com` и `translate.yandex.ru`, включая рекламу, которая появляется после загрузки страницы.

## Установка

1. Запустите `install.command` двойным кликом или из терминала.
2. На открывшейся странице включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку.

После установки обновите открытую вкладку Яндекс Переводчика. Расширение работает автоматически и не запрашивает доступ к другим сайтам.

## Обновление

После изменения файлов откройте страницу расширений и нажмите кнопку обновления на карточке расширения.
