# /stefania-memory-now

Сделать дайджест текущей сессии и положить в `personal/<login>/sessions/`. Ручной аналог автоматического `SessionEnd`-хука, на случай когда хочется зафиксировать промежуточную точку, не дожидаясь `/clear`.

## Что делать

Полный контракт — в SKILL.md скилла `stefania-memory`. Если коротко:

1. **Решить, стоит ли писать.** Применяй критерии из `~/.claude/skills/stefania-memory/SKILL.md` (раздел «Критерии писать или нет»). Если рутина без инсайтов — скажи `skipped: <короткая причина>` и завершайся, файл не создавай.

2. **Если писать — сформируй markdown** по контракту скилла:
   - Frontmatter: `type: session-digest`, `date: <сегодня>`, `session_id: <id текущей сессии если знаешь, иначе оставь пустым>`, `tickets: [<ключи из контекста>]`, `categories: [<подмножество review/task-solving/finding/decision/kb-update>]`, `tags: [session/digest]`.
   - Тело: разделы Контекст / Что сделано / Находки / Решения / Открытые хвосты / Ссылки. Пустые опускай.

3. **Дедуп.** Найди в `$VAULT_PATH/knowledge-base/personal/${STEFANIA_LOGIN:-$USER}/sessions/` файл с тем же `session_id` в frontmatter. Найден → перезапиши через Write. Не найден → новое имя `YYYY-MM-DD-<slug>.md`, slug — kebab-case из основной темы (≤50 chars, транслитерируй кириллицу). При коллизии — суффикс `-2`, `-3`.

4. **Запиши через Write.** Сообщи путь.

5. **Не пушь в Wiki.** Push — отдельная ручная операция (`stefania-knowledge-base-sync push`). Если уместно — упомяни команду в ответе.

## Чем отличается от хука

- **Контекст** — у тебя в памяти, не из транскрипта на диске. Качество выше.
- **Без `claude -p` headless** — пишешь сама.
- **Без recursion guard** — ты не флаш-воркер.
- **Без дедупа на 60 сек** — пользователь явно нажал, значит реально хочет сохранить.

## Чего НЕ делать

- Не извлекать «инстинкты» / закономерности — это отдельная задача (Instinct System).
- Не дополнять KB-справочники (`data-sources.md`, `stakeholders.md`) — это работа `stefania-knowledge-base` по ходу сессии.
- Не пушить в Wiki автоматически.
- Не писать сырой транскрипт.
